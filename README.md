# ALLGOFIX Website – Updated Version

This is the updated free GitHub Pages version of the ALLGOFIX website.

## Before publishing
Open `script.js` and replace:
- `+91 8758000713` with your real phone number
- `918758000713` with your WhatsApp number using country code, without `+` or spaces (example format: `91XXXXXXXXXX`)

The hero area and service icons are local SVG assets, so the website does not depend on an external image host.

## GitHub Pages
Upload/replace the website files in the root of your `allgofix` repository. Keep `index.html` in the repository root.
